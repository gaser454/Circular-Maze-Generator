# ⭕ Circular Maze Generator — лабиринты в полярных координатах

> «Заблудиться по-кругу — это искусство»

**Circular Maze Generator** — это набор консольных утилит для генерации лабиринтов в полярных координатах (круговые лабиринты).  
Программа создаёт идеальные лабиринты на сетке из колец и секторов с использованием различных алгоритмов.

## 🚀 Особенности
- 🧠 Поддержка алгоритмов: **DFS**, **Prim** (рандомный), **Kruskal**, **Wilson**.
- 🎯 Настройка параметров: количество колец (rings) и секторов (sectors).
- 🎨 Визуализация в терминале с использованием символов (ASCII-арт).
- 💾 Экспорт в JSON (структура данных) и SVG (векторная графика).
- 🧩 Решение лабиринта (поиск пути между центром и внешним краем).
- ⚡ Настройка seed для воспроизводимости.
- 🌀 Уникальная структура: лабиринт в виде круга с радиальными и кольцевыми проходами.

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости.

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | стандартная библиотека               | `python circular_maze.py`               |
| Go         | стандартная библиотека               | `go run circular_maze.go`               |
| JavaScript | Node.js, `fs` (стандартные)          | `node circular_maze.js`                 |
| Java       | стандартная библиотека               | `javac circular_maze.java && java circular_maze` |
| C#         | .NET (или mono)                      | `dotnet run`                            |
| Rust       | `rand`, `serde`, `serde_json`        | `cargo run`                             |
| Ruby       | стандартная библиотека               | `ruby circular_maze.rb`                 |
| PHP        | стандартная библиотека               | `php circular_maze.php`                 |
